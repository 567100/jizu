# Flask 数字编码与溢出可视化平台

## 运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install flask
python app.py
```

浏览器打开 `http://127.0.0.1:5000`。

## 功能

- 多进制（2/8/10/16）输入与输出
- 两个数字的和、差、积计算
- 原码、反码、补码、移码展示
- 第二页面：加减法与溢出检测、截断结果可视化
- 新增页面：8 功能运算器拨动开关仿真（输入控制、逻辑运算、时序输出）
- 新增第6章页面：中央处理器指令系统汇编转机器码（16位字长，支持标签）
- 右侧滚动历史记录
- 下方动态图表统计（操作类型与进制使用）
- 按钮悬浮交互效果、阴影、异常提示
